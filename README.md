# 🧑‍🎓 Sistema de Gestão de Alunos — DevTech Academy

Este projeto é um sistema simples e funcional para **cadastro e gerenciamento de alunos**, desenvolvido com **HTML, CSS, JavaScript e Bootstrap**.

---

## 🚀 Funcionalidades

- Cadastro de alunos com nome, idade, curso e nota final  
- Edição e exclusão de alunos  
- Armazenamento dos dados no **LocalStorage**  
- Relatórios automáticos:
  - Lista de alunos aprovados (nota ≥ 7)
  - Média das notas e idades
  - Nomes em ordem alfabética
  - Quantidade de alunos por curso
