# Sistema-alunos

Projeto desenvolvido como estudo de caso para o curso de Programação Web (DevTech Academy).

## 📚 Descrição
Sistema simples para **cadastrar, listar, editar e excluir alunos**, além de gerar **relatórios dinâmicos** com base nos dados.

### 🧠 Tecnologias utilizadas
- **HTML5** – estrutura do sistema  
- **CSS3** – estilização da interface  
- **JavaScript** – manipulação do DOM e lógica de CRUD  

---

## ⚙️ Funcionalidades
✅ Cadastrar alunos  
✅ Editar e excluir registros  
✅ Exibir alunos aprovados (nota ≥ 7)  
✅ Calcular médias de notas e idades  
✅ Listar nomes em ordem alfabética  
✅ Contar alunos por curso
